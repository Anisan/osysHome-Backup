# Backup - Модуль управления резервным копированием

![Backup Icon](static/Backup.png)

Комплексная система резервного копирования и восстановления для создания, управления и восстановления резервных копий системы с поддержкой базы данных, файлов, плагинов и автоматического планирования.

## Описание

Модуль `Backup` предоставляет полнофункциональную систему управления резервным копированием для платформы osysHome. Он позволяет создавать полные резервные копии системы, восстанавливать из резервных копий, управлять хранилищем резервных копий и настраивать автоматическое периодическое резервное копирование.

## Основные возможности

- ✅ **Полное резервное копирование системы**: Резервное копирование базы данных, кэша, плагинов, пользовательских файлов, ядра приложения и виртуального окружения
- ✅ **Поддержка баз данных**: Поддержка PostgreSQL и MySQL
- ✅ **Шифрование резервных копий**: Опциональное шифрование файлов резервных копий
- ✅ **Автоматическое резервное копирование**: Настраиваемое планирование автоматического резервного копирования на основе cron
- ✅ **Управление резервными копиями**: Просмотр, скачивание, загрузка и удаление резервных копий
- ✅ **Управление хранилищем**: Настройка максимального количества резервных копий и длительности хранения
- ✅ **Отслеживание прогресса**: Отслеживание прогресса резервного копирования/восстановления в реальном времени через WebSocket
- ✅ **Поддержка виджетов**: Виджет панели управления с информацией о статусе резервного копирования

## Компоненты резервного копирования

### Резервное копирование базы данных
- PostgreSQL (используя pg_dump/psql)
- MySQL (используя mysqldump/mysql)
- Автоматическое определение типа базы данных

### Резервное копирование файлов
- Директория кэша
- Директория плагинов
- Директория пользовательских файлов
- Ядро приложения
- Виртуальное окружение (venv)

## Панель администратора

Модуль предоставляет комплексный административный интерфейс:

### Главный вид
- **Список резервных копий**: Просмотр всех доступных резервных копий с деталями
- **Информация о резервной копии**: Имя, дата создания, размер, включенные компоненты
- **Действия**: Создание, восстановление, скачивание, удаление резервных копий

### Создание резервной копии
- Выбор компонентов для включения:
  - База данных
  - Кэш
  - Плагины
  - Пользовательские файлы
  - Ядро приложения
  - Виртуальное окружение
- Пользовательское имя резервной копии
- Отслеживание прогресса в реальном времени

### Восстановление резервной копии
- Выбор резервной копии для восстановления
- Автоматическая остановка циклов системы перед восстановлением
- Отслеживание прогресса
- Автоматическое возобновление циклов после восстановления

### Настройки
- **Инструменты базы данных**: Настройка путей к pg_dump, psql, mysqldump, mysql
- **Шифрование**: Включение/выключение шифрования резервных копий с управлением ключами
- **Автоматическое резервное копирование**: Настройка расписания автоматического резервного копирования (формат crontab)
- **Хранилище**: Настройка максимального количества резервных копий и длительности хранения

## Автоматическое резервное копирование

Настройка автоматического резервного копирования с использованием синтаксиса cron:

- **Формат Crontab**: `минута час день месяц день_недели`
- **Пример**: `0 2 * * *` - Ежедневно в 2:00
- **По умолчанию**: `0 2 * * *` (ежедневно в 2:00)

Автоматические резервные копии:
- Используют настройки по умолчанию из конфигурации
- Имеют префикс `auto_backup_`
- Включают временную метку в имени
- Запускают автоматическую очистку старых резервных копий

## Хранилище резервных копий

### Настройки хранилища
- **Максимальное количество резервных копий**: Максимальное количество резервных копий для хранения
- **Длительность хранения**: Дни хранения резервных копий перед автоматическим удалением
- **Очистка**: Автоматическая очистка старых резервных копий

### Формат резервной копии
- **Сжатый**: Формат `.tar.gz`
- **Зашифрованный**: Формат `.encrypted.tar.gz` (если шифрование включено)

## Виджет

Модуль предоставляет виджет панели управления, показывающий:
- Общее количество резервных копий
- Информацию о последней резервной копии (имя, дата, размер)
- Статус автоматического резервного копирования и время следующего запуска

## Использование

### Создание резервной копии

1. Перейдите в модуль Backup в панели администратора
2. Нажмите "Create Backup"
3. Выберите компоненты для включения
4. Введите имя резервной копии (опционально)
5. Нажмите "Create"
6. Отслеживайте прогресс в реальном времени

### Восстановление резервной копии

1. Перейдите в модуль Backup
2. Найдите резервную копию для восстановления
3. Нажмите "Restore"
4. Подтвердите восстановление
5. Отслеживайте прогресс
6. Система перезапустит циклы после восстановления

### Настройка автоматического резервного копирования

1. Перейдите в настройки Backup
2. Включите "Auto Backup"
3. Установите расписание crontab (например, `0 2 * * *` для ежедневного запуска в 2:00)
4. Сохраните настройки

### Загрузка резервной копии

1. Перейдите в модуль Backup
2. Нажмите "Upload Backup"
3. Выберите файл `.tar.gz` или `.encrypted.tar.gz`
4. Файл будет добавлен в список резервных копий

- **Формат резервной копии**: Архив TAR.GZ

- **Многопоточность**: Фоновые операции резервного копирования/восстановления
- **WebSocket**: Обновления прогресса в реальном времени
